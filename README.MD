\# ConcurrencySim



🇺🇸 \*\*English\*\* | 🇧🇷 \*\*Português\*\*



\## 🇺🇸 English



ConcurrencySim is a desktop application developed in Java for simulating task scheduling and visualizing execution across multiple CPU cores.



The project provides a graphical interface for configuring tasks, monitoring their execution states, and analyzing scheduling behavior through Gantt charts.



\### Features



\- Task creation and configuration

\- EDZL scheduling algorithm

\- Multicore simulation (1, 2 or 4 CPUs)

\- Gantt chart visualization

\- Task state monitoring

\- Manual and automatic simulation



\### Technologies



\- Java

\- Java Swing

\- Apache Maven



\### Execution



Download the executable `.jar` file from the Releases section.



Run using:



```bash

java -jar ConcurrencySim-1.0.0.jar

```



Requires Java 21 or higher.

\## 🇧🇷 Português



O ConcurrencySim é uma aplicação desktop desenvolvida em Java para simular o escalonamento de tarefas e visualizar sua execução em múltiplos núcleos de processamento.



O projeto oferece uma interface gráfica para configurar tarefas, acompanhar seus estados de execução e analisar o comportamento do escalonamento por meio de gráficos de Gantt.



\### Funcionalidades



\- Criação e configuração de tarefas

\- Algoritmo de escalonamento EDZL

\- Simulação multicore (1, 2 ou 4 CPUs)

\- Visualização por gráfico de Gantt

\- Monitoramento dos estados das tarefas

\- Simulação manual e automática



\### Tecnologias



\- Java

\- Java Swing

\- Apache Maven



\### Execução



Baixe o arquivo `.jar` executável na seção Releases.



Execute utilizando:



```bash

java -jar ConcurrencySim-1.0.0.jar

```



Requer Java 21 ou superior.
