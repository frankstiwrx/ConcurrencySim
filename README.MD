# ConcurrencySim

**English** | **Português**

## English

ConcurrencySim is a Java desktop application for simulating task scheduling across multiple CPU cores, with Gantt chart visualization.

### Features
- Task creation and configuration
- EDZL scheduling
- Simulation with 1, 2 or 4 CPU cores
- Gantt chart visualization
- Manual and automatic simulation

### Technologies
Java · Swing · Maven

### Run
Download the executable JAR from **Releases** and run:

```bash
java -jar ConcurrencySim-1.0.0.jar
```

Requires Java 21 or later. A Windows portable package is also available in Releases.

## Português

O ConcurrencySim é uma aplicação desktop em Java para simular o escalonamento de tarefas em múltiplos núcleos de CPU, com visualização em gráfico de Gantt.

### Funcionalidades
- Criação e configuração de tarefas
- Escalonamento EDZL
- Simulação com 1, 2 ou 4 núcleos de CPU
- Visualização em gráfico de Gantt
- Simulação manual e automática

### Tecnologias
Java · Swing · Maven

### Execução
Baixe o JAR executável na seção **Releases** e execute:

```bash
java -jar ConcurrencySim-1.0.0.jar
```

Requer Java 21 ou superior. Uma versão portátil para Windows também está disponível em Releases.
